Seguridad Criptográfica UNACH

Demostración de Mecanismos Criptográficos

Cifrado Simétrico (AES-256-GCM) en base de datos y Firma Digital Asimétrica (RSA-PSS / SHA-256) para verificación de integridad.

Demostración del Flujo Completo en Base de Datos

Compara el dato original, el texto cifrado real almacenado en la Base de Datos (hexadecimal) y la vista descifrada que recibe el usuario.

1. Vista Usuario: Texto plano descifrado tras validación.
2. Base de Datos: Formato seguro <iv>:<tag>:<ciphertext> en almacenamiento persistente.
3. Integridad: Firma digital RSA-PSS con hash SHA-256.

Laboratorio Interactivo de Cifrado Simétrico

Prueba el algoritmo AES-256-GCM ingresando cualquier texto. Observa el vector de inicialización (IV), el tag de autenticación y cómo el sistema rechaza modificaciones no autorizadas.

Par de Claves Asimétricas RSA-4096

La clave pública es distribuible libremente y permite verificar firmas digitales. La clave privada se mantiene protegida exclusivamente en el servidor.

Almacenamiento Seguro de la Clave Privada:

El archivo keys/private.pem nunca se expone por API ni se incluye en el control de versiones (excluido en .gitignore). En el servidor se lee mediante fs.readFileSync con permisos de solo lectura para el propietario del proceso (0o600).

Ficha Técnica y Justificación de Librerías

Detalle de los requerimientos técnicos y diseño de seguridad de la aplicación.

Cumplimiento de Requisitos de la Rúbrica:
Cifrado Simétrico: Protege título y contenido de noticias en Base de Datos con AES-256-GCM. El dato entra en claro, se cifra con IV aleatorio de 12 bytes y se almacena en formato iv:tag:ciphertext; al leerlo se descifra y verifica el Auth Tag.
Firma Asimétrica: Cada noticia es firmada digitalmente con un par RSA-4096 y esquema RSA-PSS con hash SHA-256. Resuelve el caso real de verificación de integridad y no repudio contra manipulaciones en base de datos.
Librería Criptográfica Establecida: Se emplea crypto nativo de Node.js (OpenSSL), sin reimplementaciones manuales y sin librerías externas no auditadas.
Gestión de Llaves Fuera del Código: La clave simétrica reside en AES_KEY (variable de entorno en .env); el par RSA reside en el directorio keys/ ignorado por git.
Datos de Prueba Inventados: Todas las noticias precargadas en el seed corresponden a datos periodísticos y tecnológicos inventados para propósitos académicos.
